# Water caustics with shark demo

## Overview
This demo combines GPU-accelerated water simulation, caustic raytracing, and an animated swimming shark in WebXR and desktop modes.

For a detailed breakdown of the shark skin texturing, skeletal animation, and underwater caustic shader integration, see [TECHNICAL_INFO.md](./TECHNICAL_INFO.md).
